# Sample product catalogue

`Updated_Product_Catalogue.xlsx` is the original 200-row Excel workbook supplied with the project. Use it to test the Excel import feature. It is sample/reference catalogue data, not a certified live stock count. The importer interprets `Stock Available` Yes/No as 10/0 opening units because the source workbook does not contain a numeric stock-on-hand field. Confirm physical stock before live checkout.


`Retail_Wizard_Test_Dataset.xlsx` and `Retail_Wizard_Test_Products.csv` are small eight-product fixtures intended for a fresh/test database. The Excel file also contains a test checklist. They are sample values, not real inventory. Do not repeatedly import the same SKUs into a live database.
