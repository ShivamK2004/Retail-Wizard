# Changelog

## 1.0 — Current application version
- Set the published application version to 1.0. Earlier numbered entries below are retained as development history.

## 2.1.4 — 2026-11-13
- Added a dashboard date/time clock that uses the computer's local time and updates every second.
- Dashboard sales, transaction counts and recent transactions refresh automatically every 15 seconds, with a manual Refresh action.
- Dashboard recent-sale timestamps are displayed in the computer's local timezone.
- Corrected Sales Today and monthly sales calculations to convert SQLite UTC timestamps to local time before grouping by date/month.
- Added regression tests for sales close to local midnight and sales from the previous local day.

## 2.1.1 — 2026-11-12
- Reserved a fixed POS checkout footer so Cash and UPI actions remain visible on laptop-sized displays.
- The checkout button changes its label and helper text with the selected payment method.
- Cash checkout uses the computed total, validates tendered cash, records the sale and attempts PDF invoice generation; the amount resets only after a successful sale.
- Replaced generated-VPA QR creation with the store-owned image at `assets/store_upi_qr.png`; UPI confirmation is disabled if the merchant QR image is missing or invalid.
- UPI displays the amount due alongside the static QR, captures UTR/reference and requires cashier confirmation before recording the sale and generating the invoice.
- Added merchant QR setup instructions and removed the no-longer-needed QR generator dependency.

## 2.1.0 — 2026-11-12
- Replaced the stacked first-run setup/login flow with a welcome screen offering separate Register and Login actions.
- Registration creates the first administrator and cashier accounts thereafter; existing screens are destroyed during navigation to avoid overlapping pages.
- Rebuilt the product dialog with a scrollable form and pinned Save/Cancel controls.
- Moved the POS Add to cart action above the product grid and added quantity controls for selected cart lines.
- Cash received auto-fills from the cart total until manually edited.
- Added a dedicated UPI checkout window with generated UPI QR, transaction reference, and manual bank-app confirmation before sale/invoice creation.
- Added an explainable, offline AI-assisted business-insights page.
- Added automated tests for the insight engine and UI smoke checks.

## 2.0.0
- Initial modular SQLite/Tkinter upgrade with product, POS, sales, refund, purchase, expense, reporting, security and backup workflows.


## 2.1.2
- Added Dashboard transaction selection, double-click and View details action.
- Added transaction details showing historical unit purchase cost, total COGS and gross profit estimate.
- Added local voice announcements after successful sale recording (Windows SAPI; offline).
- Added automatic support for `.jpeg`, `.jpg` and `.png` merchant QR filenames.
- Clarified that genuine automatic UPI detection requires provider Dynamic QR / Gateway integration with server-side transaction verification.

## 2.1.6 - Transaction details and invoice actions

- Display transaction timestamps in the computer's local time, matching the dashboard.
- Use local time on invoice PDFs generated by the application.
- Keep Print invoice and Download invoice (PDF) actions in a fixed footer on the transaction details window.
- Printing falls back to opening the PDF viewer if the Windows print action is unavailable.
